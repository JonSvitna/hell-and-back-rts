
# PROJECT VISION

## OVERVIEW
A mobile-first RTS delivering cinematic battles with tactical depth and simplified controls.

## DESIGN PILLARS
- Readability over realism
- Depth over complexity
- Speed over scale (for MVP)
- Identity over symmetry

## MVP SUCCESS CRITERIA
- Player understands battlefield in <3 seconds
- Controls feel natural within 60 seconds
- Match loop is enjoyable within 5 minutes
