
# GAME SCOPE GUARDRAILS

## HARD LIMITS
- 1 map
- 1 playable faction (initial)
- 30–50 unit cap
- 5–8 min matches

## DO NOT BUILD
- Ranked systems
- Large tech trees
- Complex economy
- Hero dominance systems

## FUTURE: WARFARE MODE
- 15–30 min matches
- Larger scale
- Config-driven only (NOT built now)
