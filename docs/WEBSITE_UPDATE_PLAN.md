# Hell & Back RTS — Website Update Plan

## Purpose

This document keeps the website update focused on traction, clarity, and conversion.

The website is already deployed at:

https://hell-and-back-rts.vercel.app/

The next update should improve the existing site without drifting into full game development.

## Creative Direction

Hell & Back should feel like a premium mobile RTS built for iOS.

The website should communicate:

- Fast mobile strategy
- Clear faction identity
- Short tactical battles
- High replay value
- Early access momentum

The site should feel like a war-room recruitment screen, not a generic game landing page.

## Locked Decisions

The faction names are locked and should not be changed:

- Vanguard
- Ascendancy
- Hive

The site should continue using the strong faction-card direction already present.

## Primary Goal

The primary goal is to get visitors to join the early access list.

Everything on the page should support one question:

> Would I want to command one of these factions on my phone?

## Website Priority

The site should prioritize:

1. A stronger hero section
2. Mobile-first gameplay credibility
3. Faction selection energy
4. Clear early access CTA
5. Social-shareable sections

## What Should Stay

Keep:

- Dark cinematic RTS tone
- Faction stat cards
- Glowing border treatment
- Military/sci-fi HUD feeling
- Short punchy faction descriptions
- The existing faction names
- Early access CTA

## What Should Improve

Improve:

- Make the hero section more emotional and mobile-specific
- Show the game is iOS/mobile-first earlier
- Add stronger CTA language
- Add faction choice interaction or visual emphasis
- Reduce any copy that feels generic
- Make sections feel like part of one cinematic system
- Make the site more useful for traction and social posting

## Do Not Add Yet

Do not add:

- Full game backend
- Unity integration
- Authentication
- Matchmaking
- Player accounts
- Inventory systems
- Overcomplicated lore pages
- Huge multi-page navigation

This phase is website traction only.

## Recommended New Page Flow

1. Hero / Early Access
2. Factions
3. Mobile Gameplay Promise
4. Why It Works on Mobile
5. Early Access CTA

## Section 1 — Hero

Goal:
Make visitors immediately understand the game.

Recommended headline:

Command Your Army. Go Through Hell. Come Back Victorious.

Alternative headline:

Mobile RTS Warfare Built for Fast Command.

Recommended subheadline:

Hell & Back is a faction-based mobile RTS for iOS, built around fast battles, readable units, and real-time tactical decisions.

Hero CTA:

- Get Early Access
- Choose Your Faction

Hero visual direction:

A stylized mobile gameplay display showing a battlefield from a top-down angle with readable units, ability buttons, faction color accents, and a war-room HUD feeling.

## Section 2 — Factions

Goal:
Make users emotionally pick a side.

Add a section headline:

Choose Your Command Style.

Add section subtext:

Three factions. No mirror matches. No safe choices. Every army changes how you fight.

Keep cards for:

- Vanguard
- Ascendancy
- Hive

Add a micro-CTA under the cards:

Which faction would you command?

Buttons:

- I command Vanguard
- I command Ascendancy
- I command Hive

These can initially scroll to the waitlist form or prefill a hidden faction field later.

## Section 3 — Mobile Gameplay Promise

Goal:
Make the idea feel playable, not just cinematic.

Headline:

Built for Your Thumb, Not a Keyboard.

Copy:

Tap to command. Drag to reposition. Trigger abilities in real time. Every decision is built for fast mobile battles without losing the RTS feeling.

Feature cards:

- 3–5 minute battles
- Clean unit readability
- Tap-and-drag control
- Tactical abilities
- Faction-based counters

## Section 4 — Why Mobile RTS Needs This

Goal:
Position the game against the pain of existing mobile strategy games without naming competitors.

Headline:

Strategy Without the Waiting Game.

Copy:

Hell & Back is designed for players who want tactical decisions now — not timers, clutter, or endless base menus.

Bullets:

- Fast matches
- No bloated economy screens
- No passive waiting loops
- Readable battlefield design
- Every faction has a clear identity

## Section 5 — Final CTA

Goal:
Convert visitors.

Headline:

Be First to Go to Hell & Back.

Subtext:

Join the early access list for faction reveals, development updates, and iOS playtest opportunities.

CTA button:

Get Early Access

Optional field:

Email address

Optional dropdown later:

Faction choice: Vanguard, Ascendancy, Hive

## Success Criteria

The update is successful if:

- A visitor understands the game in under 7 seconds
- The factions feel distinct
- The site clearly feels mobile-first
- The early access CTA is obvious
- The page feels premium but not cluttered
- The design supports social sharing
